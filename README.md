# 📚 Sistema de Gerenciamento de Biblioteca


Um sistema de gerenciamento de biblioteca desenvolvido em Java com foco em controle de usuários, reservas e penalidades.

---

## 🎯 Sobre o Projeto

Sistema para gerenciamento de bibliotecas acadêmicas, permitindo o cadastro e controle de diferentes tipos de usuários (alunos, professores e técnicos) com limites de reservas diárias personalizados por perfil.

---

## ✨ Funcionalidades

- ✅ **Cadastro de usuários** (Aluno, Professor, Técnico)
- ✅ **Controle de reservas** com limites diários por perfil
  - Aluno: 2 reservas/dia
  - Professor: 5 reservas/dia
- ✅ **Gerenciamento de penalidades** (em desenvolvimento)
- ✅ **Sistema de autenticação** por ID, nome e email
- ✅ **Controle de matrícula** (alunos) e SIAPE (professores)
- ✅ **Estatísticas** como total de alunos cadastrados
